## Как это добро запустить

Вы можете запустить проект по старинке (ручками) или по-модному (через Docker).

### Вариант 1: По-модному (Docker) 🐳

Самый простой способ, чтобы не возиться с установкой Питона и зависимостей на комп:
1. Установите Docker Desktop.
2. Откройте терминал в папке проекта и напишите:
   ```bash
   docker-compose up --build
   ```
3. Все! Сервер, база данных и окружение поднимутся сами. Приложение будет доступно по адресу: http://localhost:5000

### Вариант 2: Классический (Ручками) 🛠

Нужна нода (Node.js) и питон (Python).

1. Ставим зависимости бэкенда:
   ```bash
   cd backend
   npm install
   ```

2. Чтобы работало извлечение текста из файлов, нужен питон и пара библиотек:
   ```bash
   pip install Pillow
   ```

3. База данных
   Тут юзается sqlite (чтоб не париться с настройкой постгреса на компах колледжа). 
   Если запускаете первый раз, надо накатить таблички:
   ```bash
   npm run db:init
   ```

4. Заливаем тестовые данные (чтобы не сидеть в пустой системе):
   ```bash
   npm run db:seed
   ```

5. Запуск
   Переименуйте файл `.env.example` в `.env` (если его нет). Затем запускаем:
   ```bash
   npm run dev
   ```

Сервак должен подняться на порту 5000: http://localhost:5000
(если пишет что порт занят, убивайте процесс `npm run kill-port` или через диспетчер задач закрывайте ноду).
